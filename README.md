A newspaper front page summarising 26 November 2026 in a single image: 46 verified stories, 7 regions, unconfirmed reports labelled CLAIM.

## Run it

```sh
python3 render.py   # writes entry.png (1024x1024, deterministic)
python3 main.py     # copies entry.png to /output/entry.png
```

- Image generated by code, no AI imagery. `render.py` (Python + Pillow) draws the front page from `stories.json`. No network at run time.
- Every story dated 26 November 2026 and sourced; unconfirmed reports are labelled CLAIM.
- Run `render.py` twice: the output bytes are identical (deterministic).
- Output: `entry.png` — 1024×1024, ~179 KB (limit 1 MiB).
